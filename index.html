API REST

API de almoxarifado

Controle de estoque de uma empresa pequena: cadastro de produtos, entradas e saídas, alerta de estoque mínimo e relatórios. Dá pra testar pela documentação interativa com as contas de demonstração.

  • Três perfis de acesso (admin, operador e leitura) com login por token JWT e senha com hash Argon2
  • O saldo nunca fica negativo, nem com duas saídas ao mesmo tempo. Tem teste disso no PostgreSQL
  • Migrations com Alembic, Docker e CI que roda os testes em SQLite e em PostgreSQL

Automação de planilhas

Consolidador de planilhas de vendas

Cada loja manda a planilha do mês de um jeito. O consolidador lê todas, corrige o que dá, separa o que não dá e devolve o fechamento em Excel com resumo, gráfico e a lista das linhas descartadas com o motivo.

  • Acha o cabeçalho mesmo com título antes e entende colunas com nomes diferentes
  • Converte data e valor digitados como texto e confere se o total bate com quantidade x preço
  • Upload protegido contra arquivo falso, macro e zip bomb, com 72 testes

Python · pandas · openpyxl · FastAPI

Análise de dados

Quando o voo atrasa no Brasil

Análise de 783 mil voos domésticos registrados pela ANAC em 12 meses. Voo das 22h atrasa cerca de 5 vezes mais que o das 6h, e boa parte da diferença entre as empresas vem de Guarulhos.

  • Limpeza e análises em SQL no DuckDB, com o motivo de cada linha descartada
  • Relatório com gráficos, recomendações e as limitações dos dados
  • Testes da limpeza com uma amostra que cobre os casos problemáticos

SQL · DuckDB · Python · matplotlib

Sistema com login

Agenda para barbearia

O cliente marca serviço e horário por um link, sem criar conta. O barbeiro vê a agenda do dia no celular, marca quem já foi atendido e edita serviços, preços e horário de funcionamento.

  • Uma regra no próprio banco impede dois agendamentos no mesmo horário, mesmo que dois clientes confirmem ao mesmo tempo
  • Cada barbearia só enxerga os próprios dados (Row Level Security, testado simulando outro usuário)
  • Tem conta de demonstração que volta ao original toda madrugada

Como trabalho

Antes de escrever código, eu entendo o que precisa ser resolvido e mando uma proposta por escrito com o que entra, o prazo e o valor. Se algo mudar no caminho, a gente combina antes.

Durante o projeto você acompanha por um link de teste, não só no final. No fim, o código fica no seu GitHub, com um README explicando como rodar e publicar, pra você não depender de mim.

Segurança não fica pra depois: validação de dados no servidor, permissões no banco e testes automatizados fazem parte de todos os projetos acima.
